# Bar do Mimico Delivery

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador para testar localmente.
3. Para publicar, envie os três arquivos (`index.html`, `style.css`, `app.js`) para uma hospedagem estática como Vercel ou Netlify.

## Administração
- Clique em "Área administrativa".
- Senha inicial: `mimico123`.
- Cadastre produtos, preço, preço promocional, categoria e URL da imagem.
- Configure o frete e o WhatsApp (já preenchido com 98983280371).

## Importante antes de publicar
Este pacote é um protótipo funcional de demonstração: os dados ficam no armazenamento local do navegador. Isso significa que alterações administrativas não são compartilhadas automaticamente com outros aparelhos. Para uma loja real com administração centralizada, configure um projeto Supabase, banco de dados, armazenamento de imagens e autenticação; também altere a senha inicial e proteja as permissões. O checkout abre o WhatsApp com o pedido preenchido; o cliente ainda precisa tocar em enviar.

Venda de bebidas alcoólicas somente para maiores de 18 anos. Inclua confirmação de idade e políticas de entrega/privacidade antes de operar publicamente.
